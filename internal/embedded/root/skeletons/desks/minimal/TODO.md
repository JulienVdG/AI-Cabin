# Tasks

## Structure

**Task format:**
```markdown
- [ ] **Title** (Status): one-line description
  - [ ] **Subtask**: description
```

**Statuses:**
- (TODO 🚩) - ready to start
- (In progress 🚧) - activated
- (In review 📋) - code done, tests OK, awaiting user review
- (Done ✅) - validated and committed

Tasks are grouped under ### sections (themes or objectives).
