# OpenCode Go Cabin

**Production cabin** for Go projects using OpenCode with Greywall sandboxing.

## Quick Start

1. **Set environment variables** (required):
   ```bash
   export AI_CABIN_HOME=/home/user/
   export AI_CABIN_DESK=/home/user/ai-cabin-desk/
   export AI_CABIN_WORKDIR=/home/user/workdir/
   export SCW_PROJECT_ID=your-project-id
   export GIT_AGENT_NAME="AI Agent + $(git config --global user.name)"
   export GIT_AGENT_EMAIL=$(git config --global user.email)
   ```

   **Or use direnv** (recommended):
   Create a .envrc file with these variables
   ```bash
   direnv allow
   ```

2. **Setup environment**:
   ```bash
   make setup
   ```

3. **Start the cabin**:
   ```bash
   make docker-up
   ```

4. **Open in browser**:
   - Navigate to http://localhost:9090
   - Or use `make opencode` for TUI

## Commands

| Command | Description |
|---------|-------------|
| `make setup` | Setup environment (directories + config) |
| `make docker-up` | Start cabin in background |
| `make docker-down` | Stop cabin |
| `make docker-build` | Rebuild container |
| `make docker-shell` | Get bash shell inside container |
| `make docker-greyshell` | Get greywall-sandboxed shell |
| `make opencode` | Continue OpenCode session (via opencode) |
| `make docker-logs` | Follow agent logs |
| `make docker-restart-agent` | Restart agent container |

## Environment Variables

| Variable | Description | Example | Default |
|----------|-------------|---------|----------|
| `AI_CABIN_HOME` | Host home directory for agent data | `/home/user/` | _Required_ |
| `AI_CABIN_DESK` | Shared desk directory (AGENTS.md, skills/) | `/home/user/ai-cabin-desk/` | _Required_ |
| `AI_CABIN_WORKDIR` | Git repositories | `/home/user/workdir/` | _Required_ |
| `SCW_PROJECT_ID` | Scaleway project ID | `12345678-...` | _Required_ |
| `GIT_AGENT_NAME` | Git name for agent commits | `AI Agent + John Doe` | `AI Agent` |
| `GIT_AGENT_EMAIL` | Git email for agent commits | `user@example.com` | `ai-agent@vdg.name` |
| `CONTAINER_WORKDIR` | Container workdir path (advanced) | `/workspace/` | `${AI_CABIN_WORKDIR}` |

**Advanced: Remap Mode**

By default, the workdir path is the same in host and container (transparent mode).
Set `CONTAINER_WORKDIR` to remap the workdir to a different container path:

```bash
# Transparent mode (default)
AI_CABIN_WORKDIR=/home/user/workdir/
# Container path: /home/user/workdir/

# Remap mode (advanced)
AI_CABIN_WORKDIR=/home/user/workdir/
CONTAINER_WORKDIR=/workspace/
# Container path: /workspace/
```

**⚠️ Warning:** Remap mode changes session paths. Tools will save sessions with
container paths (e.g., `/workspace/...`) instead of host paths. This makes
sessions less portable and harder to debug from the host.

```
AI_CABIN_HOME=/home/user/
├── .local/share/opencode/    # OpenCode sessions
├── .local/state/opencode/    # OpenCode state
├── .config/opencode/         # OpenCode config
└── .config/greywall/         # Greywall config

AI_CABIN_DESK=/home/user/ai-cabin-desk/
├── desk/                     # Collaborative workspace (RW)
│   ├── TODO.md               # Task tracking
│   ├── AGENTS.md              # Agent instructions (source)
│   ├── retro.md              # Retro process
│   └── skills/               # AI skills (RW)

AI_CABIN_WORKDIR=/home/user/workdir/
└── (git repositories)        # Your projects (RW)
```

### Container Side

```
/home/ai_agent/
├── desk/                     # Mount: ${AI_CABIN_DESK} (single mount)
│   ├── TODO.md               # Task tracking
│   ├── AGENTS.md              # Agent instructions (source)
│   ├── retro.md              # Retro process
│   └── skills/               # AI skills
├── .local/share/opencode/    # Mount: ${AI_CABIN_HOME}/.local/share/opencode
├── .local/state/opencode/    # Mount: ${AI_CABIN_HOME}/.local/state/opencode
├── .config/opencode/         # Mount: ${AI_CABIN_HOME}/.config/opencode
├── .config/greywall/         # Mount: ${AI_CABIN_HOME}/.config/greywall
├── .cache/                   # Mount: ${AI_CABIN_HOME}/.cache
├── .bash_history             # Mount: ${AI_CABIN_HOME}/.local/state/ai-cabin/container_bash_history
└── workspace/                # Mount: ${AI_CABIN_WORKDIR}
```

### Generated Files

These files are generated by `make setup` in `AI_CABIN_HOME/.config/opencode/`:

- `AGENTS.md` - Agent instructions (copied from `desk/AGENTS.md` + workspace paths)
  - **⚠️ Do not edit directly** - Regenerated by `make setup`
  - To modify: edit `desk/AGENTS.md` (source file), then run `make setup`
- `opencode.json` - OpenCode configuration (copied from cabin)
  - **⚠️ Do not edit directly** - Copied from cabin on `make setup`
- `greywall.json` - Greywall configuration (copied from cabin)
  - **⚠️ Do not edit directly** - Copied from cabin on `make setup`

## Architecture

### Mount Strategy

| Path Type | Host → Container | Notes |
|-----------|------------------|-------|
| **Desk** | `${AI_CABIN_DESK}` → `${CONTAINER_HOME}/desk/` | Single RW mount (includes AGENTS.md, skills/) |
| **Agent Data** | `${AI_CABIN_HOME}/.local/` → `${CONTAINER_HOME}/.local/` | Same structure, different root |
| **Workdir** | `${AI_CABIN_WORKDIR}` → `${AI_CABIN_WORKDIR}` | Same path (no translation) |
| **Cache** | `${AI_CABIN_HOME}/.cache/` → `${CONTAINER_HOME}/.cache/` | Cabin-specific |

### Greywall Sandboxing

All commands run through `greywall` which enforces:
- Allowed commands (git, go, make, etc.)
- Allowed paths (workspace, desk, config)
- Network restrictions (via greyproxy)
- Resource limits (CPU, memory, processes)

**Wrapper scripts:**
- `opencode` - Runs OpenCode in greywall sandbox
- `greybash` - Interactive greywall-sandboxed shell

**Configuration:**
- `greywall.json` - Filesystem and network rules (mounted RO)
- `opencode.json` - OpenCode model and permissions
- `AGENTS.md` - Generated agent instructions (includes workspace paths, copied from `desk/AGENTS.md`)

## Greyproxy

Greyproxy credentials are injected automatically via `host.docker.internal:43080`.

**Requirements:**
- Greyproxy must be running on the host
- CA certificate copied to `greyproxy-ca.crt` during `make setup`

## Troubleshooting

### Desk Permissions

**Greywall errors** ("permission denied"):
1. Check `greywall.json` allows `~/desk` in `allowWrite`
2. Verify mount is RW in docker-compose.yml
3. Test with `make docker-greyshell` and try `echo test > ~/desk/test.txt`
4. Compare configs: `diff greywall.json $AI_CABIN_HOME/.config/greywall/greywall.json`

**OpenCode permission requests**:
1. Check `opencode.json` has `permission.external_directory` for `~/desk/**`
2. Verify the path matches your container mount (`${CONTAINER_HOME}/desk/`)
3. Compare configs: `diff opencode.json $AI_CABIN_HOME/.config/opencode/opencode.json`

### Sessions Not Saved

Check that `AI_CABIN_HOME/.local/share/opencode/` exists and is writable:
```bash
ls -la ${AI_CABIN_HOME}/.local/share/opencode/
```

### Build Fails

If greywall copy fails:
```bash
# Ensure greywall is installed on host
~/.local/bin/greywall --version

# Re-run setup
make setup
```
